# FitLog

**A focused workout library and daily training planner.** Browse exercises, review the details, build today's plan, and keep track of completed lifts.

## Technologies

- Next.js 16 with the App Router
- React 19
- Tailwind CSS 4
- Lucide React icons
- FitLog Workout API

## Key Features

1. **Workout library** — Browse exercise cards with categories, equipment, duration, calories, and ratings.
2. **Workout details** — View exercise descriptions, specifications, images, and step-by-step instructions.
3. **Daily plan and saved workouts** — Add lifts to today's plan or save them for later, with separate tabs for each list.
4. **Plan tracking** — See exercise, time, and calorie totals; mark a planned workout as done or remove it, with toast feedback.
5. **Responsive interface** — Use the workout library and plan on mobile, tablet, and desktop layouts.
